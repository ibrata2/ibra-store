# IBRA STORE — موقع نشر برامج ابراهيم الخزرجي

موقع كامل لنشر البرامج والتطبيقات: واجهة عامة + لوحة إدارة سرية + طلبات تطبيقات + رفع تلقائي على مواقع الرفع.

## شنو بالمشروع

| الملف | الشغل |
|---|---|
| `public/index.html` | الموقع العام (الرئيسية، صفحة كل برنامج، الطلبات، عن المطور) |
| `public/ibra-cp-eb21ba34/` | **لوحة الإدارة** — رابط سري، ما مربوط بأي مكان بالموقع |
| `netlify/functions/api.mjs` | السيرفر — يحفظ كل شي داخل Netlify (Netlify Blobs) |
| `.github/workflows/mirror.yml` | الرفع التلقائي من رابط GitHub إلى Google Drive / Gofile / Catbox… |

> 🔐 رابط لوحة الإدارة بعد الرفع: `https://اسم-موقعك.netlify.app/ibra-cp-eb21ba34/`
> احفظه عندك وما تنشره. تكدر تغيّر اسم المجلد لأي اسم سري تريده (وغيّره بنفس الاسم داخل `netlify.toml`).

## 1) رفع الموقع على Netlify (رابط دائم)

الموقع بيه سيرفر (Functions)، فلازم يترفع عن طريق GitHub مو سحب وإفلات:

1. سوي مستودع جديد على GitHub (مثلاً `ibrata2/ibra-store`) — **خليه Private** حتى محد يشوف الملفات.
2. ارفع كل ملفات المشروع عليه (فك الضغط وارفع المحتوى كما هو).
3. ادخل [app.netlify.com](https://app.netlify.com) ← **Add new project** ← **Import an existing project** ← GitHub ← اختار المستودع.
4. الإعدادات تنقرى تلقائياً من `netlify.toml` — اضغط **Deploy**.
5. من **Project configuration ← Environment variables** أضف:

| الاسم | القيمة |
|---|---|
| `ADMIN_PASSWORD` | كلمة سر قوية للوحة الإدارة (12 حرف أو أكثر، أرقام وحروف) |
| `GITHUB_TOKEN` | توكن GitHub (شوف الخطوة 2) — للرفع من رابط |
| `GITHUB_REPO` | اسم المستودع مثل `ibrata2/ibra-store` |

6. بعد إضافة المتغيرات: **Deploys ← Trigger deploy** حتى تشتغل.
7. من **Domain management** تكدر تغيّر الاسم إلى مثلاً `ibraprogram.netlify.app`.

✅ كل ما تعدّل ملف بالمستودع، Netlify يحدّث الموقع لحاله.
✅ التطبيقات والطلبات والصور محفوظة بـ Netlify نفسه، ما تنمسح مع التحديثات.

## 2) تفعيل "رفع من رابط GitHub" (اختياري لكن قوي)

تلصق رابط الملف من Releases، وGitHub ينزّله ويرفعه على المواقع اللي تختارها، والروابط تنضاف للتطبيق تلقائياً. رابط GitHub نفسه **ما يظهر للناس أبداً**.

**أ) التوكن (GITHUB_TOKEN):**
GitHub ← Settings ← Developer settings ← **Fine-grained tokens** ← Generate:
- Repository access: مستودع الموقع فقط (`ibra-store`)
- Permissions ← **Actions: Read and write**
- انسخه وحطه بـ Netlify باسم `GITHUB_TOKEN`

**ب) أسرار المستودع:** بالمستودع ← Settings ← Secrets and variables ← Actions ← New secret:

| السر | ضروري؟ | شنو |
|---|---|---|
| `ADMIN_PASSWORD` | ✅ نعم | نفس كلمة سر الإدارة (حتى يرجع الروابط للموقع) |
| `RCLONE_CONFIG` | لـ Google Drive | محتوى ملف إعداد rclone (تحت) |
| `PIXELDRAIN_KEY` | لـ Pixeldrain | مفتاح API من حسابك بـ pixeldrain.com |

Gofile و Catbox و BuzzHeavier يشتغلن **بدون أي إعداد**.

**ج) ربط Google Drive (مرة وحدة):**
1. نزّل rclone على حاسبتك من [rclone.org/downloads](https://rclone.org/downloads/)
2. بالـ CMD: `rclone config` ← `n` (جديد) ← الاسم `gdrive` ← النوع `drive` ← خلي الباقي افتراضي وسجل دخول بحساب كوكل لما ينفتح المتصفح.
3. اكتب `rclone config file` — يطلعلك مكان الملف، افتحه بالمفكرة وانسخ كل محتواه.
4. الصقه بسر `RCLONE_CONFIG`.
الملفات تنرفع بمجلد `IBRA-STORE` بدرايفك، وتصير "أي شخص عنده الرابط" تلقائياً.

**ملاحظات:**
- الملف لازم يكون من مستودع **Public** (أو أي رابط تحميل مباشر).
- Catbox حده 200MB. ملفات Gofile تنحذف إذا ما أحد نزّلها لفترة طويلة، فخليه رابط إضافي مو الوحيد.

## 3) استخدام لوحة الإدارة

- **تطبيق جديد**: الاسم، وصف قصير، مربع الشرح، المميزات، الكلمات المفتاحية، الأيقونة، الغلاف، صور التطبيق (اسحبها أو الصقها بـ Ctrl+V — تنضغط تلقائياً)، الفيديو (رابط يوتيوب/تيك توك/درايف أو رفع مباشر).
- **المنصات**: اختار ويندوز / أندرويد / آيفون / ماك / لينكس / ويب / تلفزيون، ولكل منصة حط أي عدد روابط.
- **رفع ملف من جهازك**: اختار أكثر من موقع — Gofile يرفع تلقائياً، والباقي (درايف، ميديافاير، ميكا…) ينفتح بتبويب وتلصق الرابط.
- **زر 🔗** بجنب الرابط يحول رابط Google Drive / Dropbox لرابط تحميل مباشر.
- **منشور جاهز**: نص للتيليكرام والفيسبوك والانستا/تيك توك، بيه رابط صفحة البرنامج بموقعك (بدون GitHub).
- **الطلبات**: غيّر الحالة (جديد / قيد الدراسة / قيد التطوير / تم / غير ممكن) واكتب رد يظهر للناس.
- **Ctrl+S** يحفظ التطبيق.
- **نسخة احتياطية**: نزّل ملف JSON بكل البيانات بين فترة وفترة.

## الحماية
- كل أوامر التعديل يتأكد منها السيرفر بكلمة السر — الواجهة العامة ما تكدر تغير أي شي.
- 5 محاولات غلط بكلمة السر = قفل 15 دقيقة لنفس الـ IP.
- اللوحة برابط سري + ممنوع فهرستها بمحركات البحث.
- كلمات سر الحسابات مشفّرة (scrypt)، وطلبات الزوار عليها حد ضد السبام.
